# iCOMM Local Gateway App

Local A. O. Smith iCOMM heater control and MQTT discovery, with an authenticated
Home Assistant ingress UI. Tested profile: EE9-50H55DV-A / ResElec3 firmware1.8.

See [Documentation](DOCS.md). This App is experimental. Physical factory-fresh,
fully cloud-blocked enrollment remains unverified. Standalone Docker Compose is
also supported from the repository root; HACS is not used for either path.
